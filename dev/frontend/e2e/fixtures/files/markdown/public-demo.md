# Markdown表示サンプル

見出し、文章、表、コードなどの表示をこの公開ページで確認できます。

## 文章とリンク

**太字**、_斜体_、~~取り消し線~~、`インラインコード`を同じ段落に並べます。
[外部リンク](https://example.com)も通常のリンクとして表示されます。

### 引用

> 重要なポイントは引用として強調されます。
> **太字**も引用内で使用できます。

## リスト

- 箇条書きの一項目目
- 箇条書きの二項目目
  - 入れ子の項目

1. 番号付きの一項目目
2. 番号付きの二項目目

- [x] 完了したタスク
- [ ] 未完了のタスク

## 表

| 記法   |            表示例 |
| :----- | ----------------: |
| 強調   |              太字 |
| コード | `const value = 1` |

## コードブロック

```ts
const message = "公開プレビュー";
console.log(message);
```

---

## HTMLの扱い

生HTMLは公開Markdownでは描画しません。HTMLのコード例は次のようにフェンス内へ記載できます。

```html
<strong>コードとして表示するHTML</strong>
```
